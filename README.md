# All of Us Phase 1 Selection Mapping

Code used to generate figures on Verily Workbench for the All of Us Phase 1 Long Reads companion paper "Evolution-guided association mapping using long-read genomes from a self-identified Black or African American cohort in All of Us" on demographic history, genome-wide selection, phenotype associations, and local ancestry in admixed African American participants.

| Main figure | Subject | Notebook | Scripts |
| --- | --- | --- | --- |
| 1 | Cohort characteristics, ancestry, geographic interpolation, demographic history | [Figure_1.ipynb](notebooks/Figure_1.ipynb) | `figure1_data.py`, `figure1_admixture.py`, `figure1_idw.py`, `figure1_demography.py`, `figure1_plots.py` |
| 2 | Admixture mapping, prediction, KCNJ18/HLA association examples | [Figure_2.ipynb](notebooks/Figure_2.ipynb) | `figure2_1025.py`, `figure2_1025_plots.py`, `figure2_loci.py`, `figure2_locus_figures.py` |
| 3 | Selection scan, EHH, enrichment | [Figure_3.ipynb](notebooks/Figure_3.ipynb) | `figure3_data.py`, `figure3_ehh.py`, `figure3_enrichment.py`, `figure3_plots.py` |
| 4 | PheWAS discovery, effect attenuation, meta-analysis | [Figure_4.ipynb](notebooks/Figure_4.ipynb) | `figure4_meta.py`, `figure4_effect_meta.py`, `figure4_plots.py` |
| 5 | ADH, ZMYM1, THRAP3 fine-mapping and selection examples | [Figure_5.ipynb](notebooks/Figure_5.ipynb) | `figure5_locus_composites.py`, `figure5_sv_locus_composites.py` |
